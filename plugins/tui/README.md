# tether-plugin-tui

Терминальный интерфейс для [tether](../../README.md) на [Textual](https://textual.textualize.io/). Это обычный фронтенд-плагин: пакет регистрирует entry point `tether.frontends: tui`, ядро о нём ничего не знает.

## Установка и запуск

```bash
# из корня репозитория tether
uv tool install --python 3.14 . --with ./plugins/tui
tether chat --ui tui
```

Чтобы TUI открывался по умолчанию, в `tether.yaml`:

```yaml
host:
  frontends: [tui]
  tui: {theme: tokyo-night, images: auto}   # опции фронтенда, необязательно
```

## Что умеет

- Потоковый вывод ответа модели в Markdown, размышления модели свёрнуты.
- Вызовы инструментов строкой `✓ shell  git status`; раскрываются по клику или Enter и показывают аргументы и результат.
- Подтверждение инструментов в диалоге: `y` разрешить, `a` разрешать этот инструмент до конца сессии, `n` запретить. Какие инструменты спрашивают, задаёт `host.approvals`.
- Вопросы модели через `AskUser` (включите `- AskUser: {}` в `capabilities`): варианты или свой ответ, `ctrl+s` ответить, `esc` отказаться.
- Картинки прямо в чате через kitty graphics protocol (Unicode-плейсхолдеры): изображения из результатов инструментов и команда `/image путь.png`. Работает в kitty и Ghostty, Sixel не поддерживается. `images: auto` определяет терминал сам, `on` включает принудительно, `off` выключает; без поддержки вместо картинки строка-подпись. Нативно читается PNG, другие форматы только если установлен Pillow.
- Строка статуса: модель, токены за сессию, индикатор работы.
- Команды плагинов с автодополнением (`/help` показывает список), плюс `/clear` и `/exit`.

Клавиши: `esc` отменяет текущий ход, `ctrl+l` очищает экран (история диалога сохраняется), `ctrl+q` выход, `ctrl+p` палитра команд Textual.
